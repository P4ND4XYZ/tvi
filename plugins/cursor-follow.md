# カーソル追従

[プラグイン一覧に戻る](README.md)

同じホスト・同じHerdrサーバーの同じタブ内で、tviがNeovimのMarkdownファイルとカーソル行に追従します。tvi側で受信を有効にする必要があります。追従してもフォーカスは移動しません。

## 利用方法

1. [plugins/follow.lua](follow.lua) を、tviの [`init.lua`](../docs/features/lua.md#起動時の設定) と同じディレクトリの `plugins/follow.lua` にコピーします。旧版をコピー済みの場合は、新版を同じ場所にコピーし直してください。
2. tviの `init.lua` で次のように受信を開始し、対象文書を開きます。
3. 対応する送信側の設定があるNeovimで、tviと同じタブでMarkdownファイルを開きます。送信は起動時に有効になります。停止は `:TviFollow off`、再開は `:TviFollow on` です。

```lua
require("plugins.follow").start()
```

| 操作 | 結果 |
|---|---|
| `require("plugins.follow").start()` | 受信を開始する。失敗時は状態欄に理由を表示し、`nil, err` を返す |
| `require("plugins.follow").stop()` | 受信を終了する。既定のキー割り当ては変更しない |

## 動作と制約

- `HERDR_TAB_ID` が必要です。表示名ではなくIDで宛先を区別します。受信するtviは1タブにつき1つです。
- IDが一致すると、絶対パスが同じ場合は現在の文書内をスクロールします。異なる場合は、拡張子が `.md` または `.markdown` のファイルを開いてから指定行に移動します（拡張子の大文字・小文字は区別しません）。開けなければ現在の文書と表示位置を維持します。
- ファイルを開き直すと閲覧履歴に残り、`Ctrl-o` で戻れます。絶対パスは文字列で比較するため、同じファイルでもパス区切りなどの表記が違えば開き直します。
- コマンド・検索入力、ヘルプ、フロートの表示中に届いた位置は破棄し、本文に戻ってから適用しません。
- tviは保存済みの内容を表示します。Neovimの未保存の編集で行番号がずれることがあります。tviの文書の行数を超えた指定は[末尾行として扱います](../docs/features/lua.md#元ファイルの行への移動)。
- ポートが競合する場合は、両方に同じ `TVI_FOLLOW_PORT` を設定して起動してください。1〜65535の十進整数だけが有効です。未指定時はタブIDから決まり、競合しても別のポートへの切り替えは行いません。
- 接続は `127.0.0.1` に限定されます。IDは認証情報ではなく、同じホストの別のプロセスが接続して対象ファイルを開かせることも可能です。複数のHerdrサーバーが同じIDを使う構成は対象外です。

## 送信側との取り決め

- 既定ポートは、IDのUTF-8バイトをDJB2（初期値5381、各バイトで `hash = (hash * 33 + byte) % 4294967296`）で処理し、`20000 + hash % 40001` とします。
- 1接続につき `ID<TAB>行番号<TAB>絶対パス<LF>` を1行送信し、応答は待ちません。行番号は1から始まる十進整数、パス中のタブはパスの一部です。長さなどの制約は[ローカルでの行の受信](../docs/features/lua.md#ローカルでの行の受信)を参照してください。
