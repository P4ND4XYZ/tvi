# tvi 仕様書

## 目的

tviは、端末上でMarkdownファイルを読むための閲覧専用ビューアです。
Vimライクなキー操作で文書を移動・検索できるようにし、編集機能は持ちません。

## 利用の流れ

1. `tvi README.md`のように、閲覧するファイルを指定して起動します。
2. Markdownを読み、スクロールや検索で目的の箇所へ移動します。
3. 必要に応じてコマンドやキー一覧を利用し、閲覧を終えたら終了します。

## 初期の対象範囲

UTF-8の単一ファイルのMarkdown表示、3つの動作モード、キーボードによる移動・検索を対象とします。
編集、複数ファイルの管理、リンク先への移動、画像描画、Mermaidの図としての描画、
正規表現による検索は対象外です。
