# tvi 仕様書

## 目的

tviは、端末上でMarkdownファイルを読むための閲覧専用ビューアです。
Vimライクなキー操作で文書を移動・検索できるようにし、編集機能は持ちません。

## 利用の流れ

1. `tvi README.md`のように、閲覧するファイルを指定して起動します。
2. Markdownを読み、スクロールや検索で目的の箇所へ移動します。対応端末では、独立した段落のローカル画像も本文と一緒に閲覧できます。
3. Luaでリンク一覧を設定している場合は、リンク先の文書を開いたり、元の閲覧位置に戻ったりできます。
4. 閲覧を終えたら終了します。

## 初期の対象範囲

UTF-8のMarkdownを1つの本文ビューに表示し、移動・検索、Lua設定、ローカルリンク先への移動を行えます。
Webリンクや見出しへのジャンプ、分割ウィンドウは将来の拡張候補です。
編集、外部画像の自動取得、Mermaidの図としての描画、正規表現による検索は対象外です。
