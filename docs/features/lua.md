# Lua設定と公開API

[目次に戻る](../index.md)

Luaでtviを設定し、キーの割り当てや本文ビューの操作を追加できます。

## 起動時の設定

| OS | 設定ファイル |
|---|---|
| Windows | `%LOCALAPPDATA%\tvi\init.lua` |
| Linux | `$XDG_CONFIG_HOME/tvi/init.lua`。未設定・空・相対パスの場合は `~/.config/tvi/init.lua` |

起動時に該当する `init.lua` を読み込みます。`--config` は設けません。設定ファイルがなければ通常どおり起動し、エラーがあればファイル名と理由を通知して、既定の操作で閲覧を続けられるようにします。

`require` は設定ディレクトリを基準に解決します。

## 公開API

| API | 動作 |
|---|---|
| `tvi.keymap.set(mode, keys, callback, opts)` | モード別にキーを登録する。`opts.desc` は操作の説明 |
| `tvi.colorscheme.set(styles)` | [カラースキーム](colorscheme.md)全体を置き換える |
| `tvi.ui.current_view()` | フロートではなく現在の本文ビューを取得する |
| `tvi.ui.supports_pdf()` | このセッションで[PDF表示](pdf.md)に対応していれば `true` |
| `tvi.ui.notify(message)` | 状態欄の通知だけを更新する |
| `view:document()` | 表示中の[文書ハンドル](#文書ハンドル)を返す。文書がないときだけ `nil`、ビューが閉じているときはLuaエラー |
| `tvi.process.run(program, opts)` | 指定のプログラムをシェルを介さず同期実行する。`opts.args` は文字列の配列、`opts.cwd` は作業ディレクトリ（いずれも省略可） |
| `view:open_file(path)` | 絶対パスを指定してそのビューで開く。Markdownは成功時に `true, nil`、その場での失敗時は `false, err`、PDFの読み込み開始時は `true, nil, true` を返す |
| `view:open_float(opts)` | ビューに紐づくフロートを開き、ハンドルを返す |
| `tvi.net.listen_local(port, on_line)` | `127.0.0.1` の指定ポートで受信する。成功時はハンドル、失敗時は `nil, err` |
| `listener:close()` | 受信を終了してポートを解放する。閉じたハンドルで何度呼んでもよい |
| `float:update(opts)` / `float:close()` | そのフロートの表示を更新・終了する |

キーマップの `mode` は `normal`・`command`・`search` です。
同じモードでは、本体の既定操作や利用者が登録済みの操作と同じキー列は登録できません。
キー列が操作に一致しても、より長いキー列の先頭なら、次のキーを最大300ミリ秒待ちます。
COMMANDとSEARCHでは文字入力・編集・確定・キャンセル用のキーを変更せず、未使用のショートカットを登録できます。
修飾キーや特殊キーは `<C-x>`（Ctrl-x）、`<F2>` のように書きます。`<` 自体を割り当てる場合は `<lt>` と書きます。

取得したビューハンドルはフォーカスが移っても対象が変わりません。`open_file` は失敗しても文書や閲覧履歴を変更しません。

### 文書ハンドル

`view:document()` でハンドルを取得し、`doc:type()` で表示形式を確認してから形式別の操作を使います。

| API | 形式 | 動作 |
|---|---|---|
| `doc:type()` | 共通 | 取得時の表示形式を `"md"` または `"pdf"` で返す |
| `doc:path()` | 共通 | 文書のUTF-8絶対パス、取得できない場合は `nil, err`。相対パスで起動した場合も絶対パスを返し、実体のパスへの変換や大文字・小文字の統一はしない |
| `doc:project_root(opts?)` | 共通 | 文書のディレクトリから上へ、`opts.root_markers` のいずれかを含む最も近いディレクトリを探す。既定のマーカーは `{ ".git" }`。該当なしなら文書のディレクトリ。成功時は絶対パス、失敗時は `nil, err` |
| `doc:links()` | Markdown | 対象リンクを出現順に返す。各候補は `id`、`label`、`target` を持つ |
| `doc:resolve_link(id)` | Markdown | リンク先の絶対パスを `path, nil`、失敗時は `nil, err` として返す。リンク先の存在は確認しない |
| `doc:scroll_to_line(line)` | Markdown | 元ファイルの1始まりの行へ本文をスクロールする。戻り値なし |
| `doc:zoom()` | PDF | 現在表示している倍率を返す。`1.0` は本文幅に合わせた表示 |
| `doc:set_zoom(scale)` | PDF | 倍率の変更を要求する。受付時は `true, nil`、即時拒否は `false, err`。変更が反映されるまで `zoom()` は以前の倍率を返す |
| `doc:pan_x(columns)` | PDF | 本文を横に移動する。Luaの整数型だけを受け付け、正は右、負は左、端で止まる。戻り値なし |

Markdown専用メソッドはPDFハンドルになく、PDF専用メソッドはMarkdownハンドルにありません。
文書ハンドルは取得元のビューでその文書を表示している間だけ有効です。
無効なハンドルでは `path`・`project_root`・`resolve_link` は `nil, err`を返します。 `set_zoom` は `false, err`、`type`・`links`・`scroll_to_line`・`zoom`・`pan_x` はLuaエラーになります。

### PDFの読み込み結果

PDFで第3戻り値が `true` の場合は、開く要求を受け付けた段階です。実際に表示できたときに文書を切り替え、要求元のフロートがあれば本体が閉じます。失敗すると元の文書・閲覧履歴・フロートを保ち、状態欄に理由を表示します。フロートを閉じるか、別の文書に移ると、待機中の要求は表示に反映されません。

### PDFの倍率と横移動

`set_zoom(scale)` は有限の正のLua数値（整数または浮動小数点数）を受け付けます。
[描画制限](pdf.md#倍率と横移動)を外れる倍率は拒否します。
受付後に失敗した場合は以前の倍率とページを維持し、状態欄に通知します。

`pan_x` は現在の表示に対する操作です。倍率変更の反映前に呼んだ場合は以前の表示を移動します。ページの表示準備ができていない場合や、数値文字列・`1.0` などの浮動小数点数・引数の省略など、Lua整数型以外を渡した場合はLuaエラーになります。

### 元ファイルの行への移動

`doc:scroll_to_line(line)` に渡すのは、折り返し後の表示行ではなく、読み込み済みの元ファイルの行番号です。`view:open_file(path)` でMarkdownを開いた直後に移動する場合は、`view:document()` で新しいハンドルを取得してから呼び出します。

- Luaの整数型だけを受け付けます。数値文字列、`120.0` などの浮動小数点数、`nil` や引数の省略などは `scroll_to_line: line must be an integer` のLuaエラーになります。
- 0以下は先頭行、行数を超えた指定は末尾行として扱います。LF・CRLFのどちらでも末尾の改行自体は次の行に数えず、空ファイルでは何もしません。
- 指定行の内容が最初に表示される位置を、文書の範囲内で本文領域の中央に寄せます。画像化されたMermaidの行は図の先頭を使います。表示されない行は次の表示位置へ、後続がなければ手前の最後の表示位置へ移動します。本文の表示がなければ移動しません。

### 外部コマンドの結果

`tvi.process.run` は起動したコマンドの終了を待ち、`{ stdout, ok, code }` を返します。
`stdout` はNULを含む出力をそのまま保持するLua文字列です。
`ok` は終了成功時だけ `true`、`code` は終了コードがない場合は `nil` です。
実行できなかった場合は `nil, err` を返し、実行ファイルが見つからなければ `err.kind == "not_found"` です。
`err.message` に理由が入ります。

### フロートの表示項目

| 項目 | 内容 |
|---|---|
| `title` | 枠に表示するタイトル |
| `header` | 本文をスクロールしても残る任意の1行 |
| `lines` | 本文に表示する文字列の配列 |
| `focus_line` | `lines` 内の1始まりの強調行。見える位置までスクロールし、`false` で強調を解除する |
| `on_key(float, key)` | 作成時に指定する入力コールバック。`key.name` はキー名、`key.text` は入力文字 |

`float:update` は指定された表示項目だけを更新し、`lines` を渡した場合は本文全体を置き換えます。位置とサイズは自動です。
初版はフロート1枚までとし、表示中に2枚目を開く操作は拒否します。閉じたハンドルで別のフロートは操作できません。
入力やエラー時の動作は[動作モードと入力](modes.md)を参照してください。
