# 検索

[目次に戻る](../index.md)

## 概要

表示中のMarkdownまたは[PDF](pdf.md)から文字列を探します。
検索は大文字と小文字を区別します。

## 基本の流れ

次のキーはNORMALモードで使います。検索語の入力中は `Enter` で確定し、`Esc` で取り消します。

| キー | 動作 |
|---|---|
| `/` | 前方検索の入力を開始 |
| `?` | 後方検索の入力を開始 |
| `n` | 検索と同じ方向の一致箇所へ移動 |
| `N` | 検索と逆方向の一致箇所へ移動 |

## 検索条件と移動

- 検索は表示領域の先頭を基準とします。
- 前方検索で文書の末尾に達したら先頭、後方検索では先頭から末尾へ戻ります。
- 空の検索語を確定した場合は、前回の検索語を再利用します。
- 一致がない場合や再利用できる検索語がない場合は、閲覧位置を変えず、状態欄にその旨を表示します。

## ハイライト

検索に一致した項目を青色、選択している項目を黄色として表示します。

- `:noh`または`:nohlsearch`で、検索のハイライトを無効にできます。
- 検索入力を開いて`Esc`でキャンセルしただけでは再表示しません。
