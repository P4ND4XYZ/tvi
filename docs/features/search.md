# 検索

[目次に戻る](../index.md)

## 概要

表示中のMarkdownまたは[PDF](pdf.md)から文字列を探し、一致箇所へ移動できます。
大文字と小文字を区別する文字列検索とし、正規表現は使用しません。

## 基本の流れ

次のキーはNORMALモードで使います。検索語の入力中は `Enter` で確定し、`Esc` で取り消します。

| キー | 動作 |
|---|---|
| `/` | 前方検索の入力を開始 |
| `?` | 後方検索の入力を開始 |
| `n` | 確定した検索と同じ方向の一致箇所へ移動 |
| `N` | 確定した検索と逆方向の一致箇所へ移動 |

## 検索条件と移動

- 新規検索は現在の本文表示領域の先頭を基準とし、`n` / `N`は現在の一致箇所を基準とします。
- 前方検索で文書の末尾に達したら先頭へ戻ります。後方検索では先頭から末尾へ戻ります。
- 空の検索語を確定した場合は、前回の検索語を再利用します。
- 一致がない場合や再利用できる検索語がない場合は、閲覧位置を変えず、状態欄にその旨を表示します。

検索結果の現在番号と総数を状態欄に表示します。

## Markdownの検索対象

元のMarkdownの装飾記号ではなく、表示テキストを検索します。装飾の区切りや画面上の折り返しをまたぐ文字列も検索できます。
[本文中の画像](markdown.md#本文中の画像)の代替テキストは、画像を表示できる場合はキャプションで、表示できない場合は代替表示で見つけられます。画像の読み込み結果によって一致件数は変わりません。
[Mermaidの図](markdown.md#mermaidの図)として画像を表示する場合、元のMermaidソースは検索対象にしません。変換の失敗や画像非対応の端末でコードとして表示する場合は、通常のコードブロックと同じく検索できます。[履歴から文書に戻る](links.md)と、表示テキストが同じ場合は以前の検索位置も復元します。
画面幅を変更しても検索の一致件数は変わらず、検索結果と画面上の一致箇所が対応するようにします。

## PDFの検索対象

ページ内の横書きテキストを対象に、同じ行にある文字列を検索します。行やページをまたぐ一致はありません。文字の間隔だけで表現された空白は検索語のスペースに対応しないことがあります。

一致箇所へページをまたいで移動し、文書全体での一致番号と件数を表示します。処理中は `Esc` で中止できます。中止・時間切れや抽出・表示の失敗では、ページ、閲覧位置、確定済みの検索結果を保ちます。検索による移動は[履歴](links.md)に追加しません。

画像だけのPDFは検索できません。回転や切り抜きのあるページ、原点が標準と異なるページ、非表示の文字、縦書き・傾いた文字、埋め込まれた図の文字などは対象外です。通常の横書きと混在する場合は、位置を特定できる横書きだけを検索します。PDF内の文字コードや配置、書字方向を判定できない埋め込みフォントなどにより、横書きでも見つからないことがあります。ファイルや展開後のデータが大きい場合は検索できないことがあります。開いている間にPDFを変更したときは、開き直してから検索してください。

ページ本文に `W` / `W*` で切り抜きが設定されると、元の描画状態に戻るまで、その範囲内に見えている文字も含めて検索・ハイライトの対象から外します。文字を使う切り抜き（`Tr` 4–7）も、文字ブロックの終わり（`ET`）から同じように扱います。切り抜きが有効になる前に描かれる文字（`Tr` 4–6）は検索できますが、切り抜きだけに使う文字（`Tr` 7）は検索しません。透明度、塗り重ねなどによる実際の可視性までは判定しません。

## ハイライト

現在の一致は黄色、ほかの一致は青色で表示します。Markdownの色は[カラースキーム](colorscheme.md)で変更できます。PDFでは固定の色をページ画像に半透明で重ねます。文字の位置と幅から範囲を推定するため、字形のはみ出しや複数の文字を一字形にまとめた箇所などでは、色の範囲が一致箇所とずれたり、ハイライトされなかったりすることがあります。

`:noh`または`:nohlsearch`で、検索のハイライトを無効にできます。
ハイライトの解除は検索語や一致結果の削除ではなく、`n` / `N`による移動は引き続き利用できます。
次の検索確定、または`n` / `N`による検索結果への移動で、ハイライトを再表示します。
検索入力を開いて`Esc`でキャンセルしただけでは再表示しません。
コマンド一覧は、[コマンドと終了](commands.md)を参照してください。
