# 検索

[目次に戻る](../index.md)

## 概要

表示中の文書から文字列を探し、一致箇所へ移動する機能です。
元のMarkdownの装飾記号ではなく、表示テキストを対象に検索します。
大文字と小文字を区別する文字列検索とし、正規表現は使用しません。

## 基本の流れ

1. NORMALモードで`/`または`?`を押し、SEARCHモードへ移ります。
2. 検索語を入力し、`Enter`で確定します。`Esc`では入力をキャンセルします。
3. NORMALモードで`n` / `N`を使い、確定済みの検索を繰り返します。

| キー | 動作 |
|---|---|
| `/` | 前方検索の入力を開始 |
| `?` | 後方検索の入力を開始 |
| `n` | 確定した検索と同じ方向の一致箇所へ移動 |
| `N` | 確定した検索と逆方向の一致箇所へ移動 |

## 検索条件と移動

- 新規検索は現在の本文表示領域の先頭を基準とし、`n` / `N`は現在の一致箇所を基準とします。
- 前方検索で文書の末尾に達したら先頭へ戻ります。後方検索では先頭から末尾へ戻ります。
- 空の検索語を確定した場合は、前回の検索語を再利用します。
- 一致がない場合や再利用できる検索語がない場合は、閲覧位置を変えず、状態欄にその旨を表示します。

## 装飾・折り返しとの関係

装飾の区切りや画面上の折り返しをまたぐ文字列も検索できます。
[本文中の画像](markdown.md#本文中の画像)の代替テキストは、画像を表示できる場合はキャプションで、表示できない場合は代替表示で見つけられます。画像の読み込み結果によって一致件数は変わりません。
[Mermaidの図](markdown.md#mermaidの図)として画像を表示する場合、元のMermaidソースは検索対象にしません。変換の失敗や画像非対応の端末でコードとして表示する場合は、通常のコードブロックと同じく検索できます。[履歴から文書に戻る](links.md)と、表示テキストが同じ場合は以前の検索位置も復元します。
画面幅を変更しても検索の一致件数は変わらず、検索結果と画面上の一致箇所が対応するようにします。

## 一致箇所の表示

検索の一致箇所をハイライトし、現在の一致番号と一致総数を状態欄に表示します。

`:noh`または`:nohlsearch`で、検索のハイライトを無効にできます。
ハイライトの解除は検索語や一致結果の削除ではなく、`n` / `N`による移動は引き続き利用できます。
次の検索確定、または`n` / `N`による検索結果への移動で、ハイライトを再表示します。
検索入力を開いて`Esc`でキャンセルしただけでは再表示しません。
コマンド一覧は、[コマンドと終了](commands.md)を参照してください。
