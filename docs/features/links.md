# リンク先への移動

[目次に戻る](../index.md)

## 概要

現在の文書にあるローカルMarkdownリンクを一覧から選び、別の文書へ移動する機能です。
一覧を使うには、[Lua設定](lua.md)でリンクプラグインを読み込み、起動キーを割り当てます。

## 操作

| キー | 動作 |
|---|---|
| `gl`（設定例） | NORMALモードでリンク一覧を開く |
| 文字入力 / `Backspace` | リンク名とパスをファジー検索で絞り込む。検索語が空なら文書の出現順に表示 |
| `↑` / `↓` | 候補を選ぶ |
| `Enter` | 選んだリンク先の先頭を同じ本文ビューで開き、一覧を閉じる |
| `Esc` | 一覧だけを閉じ、元の閲覧位置を保つ |
| `Ctrl-o` | NORMALモードでジャンプ前の文書・閲覧位置・本文検索の状態に戻る |

一覧の各行にはリンク名とパスを表示します。現在の文書だけが[自動再読み込み](markdown.md#自動再読み込み)の対象です。履歴から戻る際に本文が変わっていれば、変更を反映します。本文に変更がない場合も、通常画像は元のパスから読み直します。本文に変更がない場合、以前画像で表示できたMermaidの図だけを、利用できる既存キャッシュから復元し、再変換はしません。表示テキストが同じなら、以前の閲覧位置・検索結果・ハイライトの有無を復元します。図がコードに戻って表示テキストが変わった場合は、近い位置へ戻り、検索語とハイライト設定を保ったまま一致箇所を計算し直します。

## 対象と例外

- 相対パスで `.md` を指す通常リンクと参照形式リンクが対象です。`../` もリンク元の文書があるディレクトリを基準に解決します。
- 画像・Webリンク・`#見出し`・`file.md#見出し` は対象外です。見出し指定だけを無視して開くことはしません。
- 対象リンクや検索に一致する候補がない場合はその旨を表示し、`Enter` では何も開きません。
- リンク先を開けない場合は理由を一覧に表示し、元の文書・履歴・候補の選択を保ちます。
