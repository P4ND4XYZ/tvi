# 文書間の移動と復帰

[目次に戻る](../index.md)

## 概要

[Lua API](lua.md#公開api)の `view:links()` と `view:resolve_link(id)` で対象リンクとリンク先を取得できます。`view:open_file(path)` で別の文書を開くと、移動前の状態が閲覧履歴に残ります。

| キー | 動作 |
|---|---|
| `Ctrl-o` | NORMALモードで移動前の文書・閲覧位置・本文検索の状態に戻る |

現在表示中のMarkdownだけが[自動再読み込み](markdown.md#自動再読み込み)の対象です。履歴から戻る際に本文が変わっていれば、変更を反映します。本文に変更がない場合も、通常画像は元のパスから読み直します。本文に変更がない場合、以前画像で表示できたMermaidの図だけを、利用できる既存キャッシュから復元し、再変換はしません。表示テキストが同じなら、以前の閲覧位置・検索結果・ハイライトの有無を復元します。図がコードに戻って表示テキストが変わった場合は、近い位置へ戻り、検索語とハイライト設定を保ったまま一致箇所を計算し直します。

[PDF](pdf.md)に戻る場合は、以前表示していたページとその中の位置、および確定済みの検索結果を復元します。ページ送りや一致箇所への移動では履歴に項目を作りません。

## 対象と例外

- 相対パスで `.md` を指す通常リンクと参照形式リンクが対象です。`../` もリンク元の文書があるディレクトリを基準に解決します。
- 画像・Webリンク・`#見出し`・`file.md#見出し` は対象外です。見出し指定だけを無視して開くことはしません。
- 文書を開けない場合は、元の文書と閲覧履歴を保ちます。
