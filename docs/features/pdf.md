# PDF表示

[目次に戻る](../index.md)

## 開く

Windowsで、tviがKitty画像表示と文字セルの寸法を確認できた端末に限り、PDFを表示できます。拡張子は `.pdf` です（大文字・小文字は区別しません）。

`tvi file.pdf` で直接開くか、Markdownと同じ [ファイル選択](../../plugins/README.md#ファイル選択) の `ff` から開きます。ファイル選択で開けないときは、理由を状態欄に表示し、選択中の候補・元の文書・閲覧履歴を保ちます。起動時の読み込み中は `Esc` で中止できます。

## ページ内の移動とページ送り

一度に1ページを表示し、既定では本文の幅に合わせます。縦長のページは最下部までスクロールできます。

| 操作 | 動作 |
|---|---|
| 下方向の[スクロール](navigation.md) | 現在のページを下へ移動します。最下部でもう一度操作すると、次のページの先頭を表示します。 |
| 上方向のスクロール | 現在のページを上へ移動します。最上部でもう一度操作すると、前のページの末尾を表示します。 |
| `gg` / `G` | 現在のページの先頭／末尾に移動します。 |
| `Ctrl-o` | ページ送りではなく、[文書間の移動](links.md)を戻します。 |

先頭ページより前、最終ページより後には移動せず、通知も出しません。ページ送りに失敗した場合は、現在のページと位置を保ち、同じ操作で再試行できます。画面サイズを変えても、同じページ内で読んでいた位置を保ちます。

## 検索

Markdownと同じキーで、PDFに含まれる横書きテキストを検索できます。操作と制約は[検索](search.md#pdfの検索対象)を参照してください。

## 倍率と横移動

[PDFのLua API](lua.md#pdfの倍率と横移動)で倍率の変更と横移動ができます。既定のキー割り当てやコマンドはありません。倍率 `1.0` は本文幅に合わせる指定です。より大きければ拡大し、本文幅からはみ出たときは左右端まで移動できます。より小さければ縮小し、本文内に収まる場合は横移動しません。

倍率を変えても、本文領域の中央にあったページ上の位置を可能な限り保ちます。ページ送りや画面サイズの変更では倍率を維持し、新しくPDFを開いたときは `1.0` に戻ります。

変更可能な倍率の範囲はページの縦横比、本文幅、文字セル寸法で変わります。倍率を掛けた幅が1ピクセル以上で、描画が65,535列・8,192行以内、端のセルの透明部分を含めた画像が33,554,432ピクセル以内で、少なくとも1セルを画像タイルに収められることが必要です。ページの寸法は描画時にピクセル単位に丸めますが、範囲外の倍率を別の倍率に置き換えることはありません。リサイズ先や次のページが制限を超える場合も、別の倍率には切り替えず、以前の表示を維持して状態欄に通知します。

## 対象外

PDFのリンク操作、自動再読み込み、パスワード入力、OCRには対応しません。
