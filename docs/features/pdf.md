# PDF表示

[目次に戻る](../index.md)

## 開く

Windowsで、tviがKitty画像表示と文字セルの寸法を確認できた端末に限り、PDFを表示できます。拡張子は `.pdf` です（大文字・小文字は区別しません）。

`tvi file.pdf` で直接開くか、Markdownと同じ [ファイル選択](../../plugins/README.md#ファイル選択) の `ff` から開きます。ファイル選択で開けないときは、理由を状態欄に表示し、選択中の候補・元の文書・閲覧履歴を保ちます。起動時の読み込み中は `Esc` で中止できます。

## ページ内の移動とページ送り

一度に1ページを本文の幅に合わせて表示します。縦長のページは最下部までスクロールできます。

| 操作 | 動作 |
|---|---|
| 下方向の[スクロール](navigation.md) | 現在のページを下へ移動します。最下部でもう一度操作すると、次のページの先頭を表示します。 |
| 上方向のスクロール | 現在のページを上へ移動します。最上部でもう一度操作すると、前のページの末尾を表示します。 |
| `gg` / `G` | 現在のページの先頭／末尾に移動します。 |
| `Ctrl-o` | ページ送りではなく、[文書間の移動](links.md)を戻します。 |

先頭ページより前、最終ページより後には移動せず、通知も出しません。ページ送りに失敗した場合は、現在のページと位置を保ち、同じ操作で再試行できます。画面サイズを変えても、同じページ内で読んでいた位置を保ちます。

## 対象外

PDFのリンク操作、自動再読み込み、ズーム、検索、パスワード入力、OCRには対応しません。検索キーを押すと、PDFでは検索できない旨を状態欄に表示します。非常に大きいページや表示幅では、画像のメモリ上限により表示できないことがあります。
