# 文書内の移動

[目次に戻る](../index.md)

## 概要

編集カーソルを動かすのではなく、本文の表示領域をスクロールして読み進める機能です。
操作はNORMALモードで行います。

## キーバインド

| キー | 動作 |
|---|---|
| `j` / `↓` | 下へ1表示行 |
| `k` / `↑` | 上へ1表示行 |
| `Ctrl-d` / `Ctrl-u` | 下／上へ半ページ |
| `Ctrl-f` / `Ctrl-b` | 下／上へ1ページ |
| `PageDown` / `PageUp` | 下／上へ1ページ |
| `gg` / `G` | 文書の先頭／末尾 |

「1表示行」は、元のMarkdownのソース行ではなく、折り返し後の画面上の1行です。[本文中の画像](markdown.md)が占める行も数えます。
半ページ・1ページの移動量は、ステータス欄や入力欄を除いた本文表示領域の高さを基準とします。
移動しても文書の先頭・末尾を越えてスクロールしません。

検索結果への移動は[検索](search.md)、別の文書への移動と復帰は[文書間の移動と復帰](links.md)を参照してください。

## 画面サイズの変更

画面サイズが変わったら、表示幅に合わせて折り返しを調整します。
リサイズ後も、読んでいた箇所が見える状態を保ちます。
検索結果の表示との関係は、[検索](search.md)を参照してください。

## 将来の拡張候補

`10j`のような回数指定と、`]]` / `[[`による次／前の見出しへの移動は、
初期機能とは分けた拡張候補とします。
