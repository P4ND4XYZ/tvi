# コマンドと終了

[目次に戻る](../index.md)

## 概要

COMMANDモードで、終了や表示状態の変更などを指示する機能です。
NORMALモードの`:`で入力を開始し、`Enter`で実行します。
`Esc`では実行せずに入力をキャンセルします。

## コマンド一覧

表中の`:`は、COMMANDモードに入るためのキーも含めた表記です。

| コマンド | 機能 |
|---|---|
| `:q` / `:quit` | アプリを終了 |
| `:help` | キー一覧を表示 |
| `:noh` / `:nohlsearch` | 検索のハイライトを無効化 |

`:noh`は`:nohlsearch`の別名で、同じ動作をします。
解除時に保持する情報や再表示については、[検索](search.md#ハイライト)を参照してください。

## コマンドのエラー

未知のコマンドはアプリを終了させず、状態欄にエラーを表示してNORMALモードへ戻ります。

## 終了

通常終了は`:q`（別名`:quit`）で行います。NORMALモードの`q`や`Ctrl-c`には終了操作を割り当てません。
閲覧専用のため、文書の保存処理はありません。
通常終了時と、処理可能なエラーで終了する場合には、端末を通常の状態へ戻します。
