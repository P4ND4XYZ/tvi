# Markdown表示

[目次に戻る](../index.md)

## 概要

Markdownファイルを端末上で読みやすく表示する機能です。

## 基本の使い方

```sh
tvi README.md
```

入力ファイルの文字コードはUTF-8とします。

見出し、段落、リスト、引用、コードブロックなどを、Markdownの装飾を反映して表示します。
本文は画面幅に合わせて折り返します。
表が本文の幅を超える場合は、罫線と各列の最小幅が収まる範囲で、列を揃えたままセル内を折り返します。
コードブロックでは、描画ライブラリが対応する言語のシンタックスハイライトを利用します。

画面下部の状態表示については、[状態表示とヘルプ](status-help.md)を参照してください。

## 起動時のエラー

起動に失敗した場合は、標準エラー出力に理由を表示し、非ゼロの終了コードで終了します。

## 自動再読み込み

閲覧中の文書が更新された時に、表示を更新します。

- 更新時は閲覧位置をできるだけ近くに保ちます。
- 検索語とハイライトの有無を引き継いで一致箇所を計算し直します。
- ファイルが削除された場合や、通常ファイルとして読み取れない場合、UTF-8でない場合は、直前の表示を維持します。

## 本文中の画像

pngまたはjpgの画像を表示します。

```markdown
![構成図](./images/diagram.png)
```
## Mermaidの図

本文に独立して置かれた `mermaid` コードフェンスを、元のブロックの位置に図として表示します。
ただし、引用やリスト内のブロック、ほかのコードブロックに書かれたフェンスの例は、コードのまま表示します。

- mermaidの図は非同期で生成します。既にキャッシュがある場合はキャッシュを表示します。
- 変換の上限は図1枚につき10秒、未生成の図の変換開始から文書全体で30秒です。
- 別の文書への移動や本文の再読み込みで古い変換を中断します。
- PNGのキャッシュはtviの終了後も保持します。
- キャッシュ全体の上限は128 MiBです。
- キャッシュの保存先は以下の通りです。
    - Windows: `%LOCALAPPDATA%\tvi\cache\mermaid`
    - Linux: `$XDG_CACHE_HOME/tvi/cache/mermaid` あるいは `$HOME/.cache/tvi/cache/mermaid`
