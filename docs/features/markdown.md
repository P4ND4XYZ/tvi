# Markdown表示

[目次に戻る](../index.md)

## 概要

起動時に指定した単一のMarkdownファイルを、端末上で読みやすく表示する機能です。
文書は閲覧専用で、内容の編集や保存は行いません。

## 基本の使い方

```sh
tvi README.md
```

入力ファイルの文字コードはUTF-8とします。

見出し、段落、リスト、引用、コードブロックなどを、Markdownの装飾を反映して表示します。
本文は画面幅に合わせて折り返します。
コードブロックでは、描画ライブラリが対応する言語のシンタックスハイライトを利用します。

画面下部の状態表示については、[状態表示とヘルプ](status-help.md)を参照してください。

## 起動時のエラー

ファイルが指定されていない場合や、ファイルの読み込み・UTF-8としての解釈に失敗した場合は、
標準エラー出力に理由を表示し、非ゼロの終了コードで終了します。

## 表示上の制約

- ブラウザと同じ描画結果を目指すものではありません。
- 画像は画像そのものではなく、代替テキストなどで表します。
- HTMLは解釈せず、文字列として表示します。
- Mermaidは図へ変換せず、コードブロックとして表示します。

描画には`tui-markdown`を利用しますが、具体的なライブラリへの依存は
[Markdown adapter](../design/architecture.md)内に閉じ込めます。
