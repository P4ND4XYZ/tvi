# Markdown表示

[目次に戻る](../index.md)

## 概要

起動時に指定した単一のMarkdownファイルを、端末上で読みやすく表示する機能です。
文書は閲覧専用で、内容の編集や保存は行いません。

## 基本の使い方

```sh
tvi README.md
```

入力ファイルの文字コードはUTF-8とします。

見出し、段落、リスト、引用、コードブロックなどを、Markdownの装飾を反映して表示します。
本文は画面幅に合わせて折り返します。
表が本文の幅を超える場合は、罫線と各列の最小幅が収まる範囲で、列を揃えたままセル内を折り返します。
コードブロックでは、描画ライブラリが対応する言語のシンタックスハイライトを利用します。

画面下部の状態表示については、[状態表示とヘルプ](status-help.md)を参照してください。

## 起動時のエラー

起動に失敗した場合は、標準エラー出力に理由を表示し、非ゼロの終了コードで終了します。

## 自動再読み込み

閲覧中の文書を上書きまたは置き換えると表示を更新します。

- 更新時は閲覧位置をできるだけ近くに保ちます。
- 検索語とハイライトの有無を引き継いで一致箇所を計算し直します。
- ファイルが削除された場合や、通常ファイルとして読み取れない場合、UTF-8でない場合は、直前の表示を維持します。

## 本文中の画像

画像を表示するには、次のように画像1枚だけを独立した段落に置きます。

```markdown
![構成図](./images/diagram.png)
```

- 実データがPNGまたはJPEGの通常ファイルが対象です。

## Mermaidの図

本文に独立して置かれた `mermaid` コードフェンスを、元のブロックの位置に図として表示します。引用やリスト内のブロック、ほかのコードブロックに書かれたフェンスの例は、コードのまま表示します。

- `mmdc` が見つからなければ、コードを表示します。
- PNGのキャッシュはtviの終了後も保持します。次に文書を開いたとき、図のソースや変換設定が変わっていなければ再利用します。キャッシュ全体の上限はユーザーごとに128 MiBです。保存先はWindowsでは `%LOCALAPPDATA%\tvi\cache\mermaid`、Linuxでは `$XDG_CACHE_HOME/tvi/cache/mermaid`（未設定・空・相対パスの場合は `$HOME/.cache/tvi/cache/mermaid`）です。
