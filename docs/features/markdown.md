# Markdown表示

[目次に戻る](../index.md)

## 概要

起動時に指定した単一のMarkdownファイルを、端末上で読みやすく表示する機能です。
文書は閲覧専用で、内容の編集や保存は行いません。

## 基本の使い方

```sh
tvi README.md
```

入力ファイルの文字コードはUTF-8とします。

見出し、段落、リスト、引用、コードブロックなどを、Markdownの装飾を反映して表示します。
本文は画面幅に合わせて折り返します。
コードブロックでは、描画ライブラリが対応する言語のシンタックスハイライトを利用します。

画面下部の状態表示については、[状態表示とヘルプ](status-help.md)を参照してください。

## 起動時のエラー

ファイルが指定されていない場合や、ファイルの読み込み・UTF-8としての解釈に失敗した場合は、
標準エラー出力に理由を表示し、非ゼロの終了コードで終了します。

## 本文中の画像

画像を表示するには、次のように画像1枚だけを独立した段落に置きます。

```markdown
![構成図](./images/diagram.png)
```

- 現在開いているMarkdownファイルのディレクトリを基準に相対パスを解決します。`../`で外のディレクトリも指定できます。絶対パス（ドライブ指定やUNCを含む）とURLは対象外で、外部からの自動取得はしません。
- 実データがPNGまたはJPEGの通常ファイルが対象です。Windowsの対話端末では、Kittyの仮想配置に対応すると判断でき、画像プロトコルとセル寸法の問い合わせに応答した場合にピクセルで表示します。それ以外では、フルカラーを識別できれば色付きの半ブロック文字セルで表示します。Unix系では問い合わせを行わず、従来の文字セル表示を使います。
- 画像を表示できた場合は`[img]`を表示せず、代替テキストがあれば[検索](search.md)できるキャプションとして表示します。文章の途中、表やリスト内の画像、色付きセルも使えない端末、読み込めない画像では、`[img]`と代替テキスト（なければ参照先）を表示します。

## 表示上の制約

- ブラウザと同じ描画結果を目指すものではありません。
- HTMLは解釈せず、文字列として表示します。
- Mermaidは図へ変換せず、コードブロックとして表示します。

描画には`tui-markdown`を利用しますが、具体的なライブラリへの依存は
[Markdown adapter](../design/architecture.md)内に閉じ込めます。
