# Markdown表示

[目次に戻る](../index.md)

## 概要

起動時に指定した単一のMarkdownファイルを、端末上で読みやすく表示する機能です。
文書は閲覧専用で、内容の編集や保存は行いません。

## 基本の使い方

```sh
tvi README.md
```

入力ファイルの文字コードはUTF-8とします。

見出し、段落、リスト、引用、コードブロックなどを、Markdownの装飾を反映して表示します。
本文は画面幅に合わせて折り返します。
表が本文の幅を超える場合は、罫線と各列の最小幅が収まる範囲で、列を揃えたままセル内を折り返します。
コードブロックでは、描画ライブラリが対応する言語のシンタックスハイライトを利用します。

画面下部の状態表示については、[状態表示とヘルプ](status-help.md)を参照してください。

## 起動時のエラー

起動に失敗した場合は、標準エラー出力に理由を表示し、非ゼロの終了コードで終了します。

## 本文中の画像

画像を表示するには、次のように画像1枚だけを独立した段落に置きます。

```markdown
![構成図](./images/diagram.png)
```

- 実データがPNGまたはJPEGの通常ファイルが対象です。
- Kitty Graphoc Protocolの対応はWindowsのみです。
