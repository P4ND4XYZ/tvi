# Markdown表示

[目次に戻る](../index.md)

## 概要

起動時に指定した単一のMarkdownファイルを、端末上で読みやすく表示する機能です。
文書は閲覧専用で、内容の編集や保存は行いません。

## 基本の使い方

```sh
tvi README.md
```

入力ファイルの文字コードはUTF-8とします。

見出し、段落、リスト、引用、コードブロックなどを、Markdownの装飾を反映して表示します。
本文は画面幅に合わせて折り返します。
表が本文の幅を超える場合は、罫線と各列の最小幅が収まる範囲で、列を揃えたままセル内を折り返します。
コードブロックでは、描画ライブラリが対応する言語のシンタックスハイライトを利用します。

画面下部の状態表示については、[状態表示とヘルプ](status-help.md)を参照してください。

## 起動時のエラー

起動に失敗した場合は、標準エラー出力に理由を表示し、非ゼロの終了コードで終了します。

## 本文中の画像

画像を表示するには、次のように画像1枚だけを独立した段落に置きます。

```markdown
![構成図](./images/diagram.png)
```

- 実データがPNGまたはJPEGの通常ファイルが対象です。
- Kitty Graphoc Protocolの対応はWindowsのみです。

## Mermaidの図

本文に独立して置かれた `mermaid` コードフェンスを、元のブロックの位置に図として表示します。引用やリストの中にあるブロックはコードのまま表示します。外部画像などの素材に依存する図は対象外です。

- 起動時や[リンク先への移動](links.md)で文書を開くとき、`PATH` に `mmdc` があれば、キャッシュにない図をPNGに変換します。成功して正常に読み込めた画像だけを表示し、元のMarkdownは書き換えません。
- 変換を待つ時間は1図につき最大5秒、1文書につき合計で最大15秒です。変換結果を確定してから表示し、表示後の差し替えやスクロール・リサイズによる再変換は行いません。
- `mmdc` が見つからなければ、キャッシュがあっても使わず、通知せずにコードを表示します。変換に失敗した図、制限時間内に変換できなかった図、PNGを読み込めなかった図は、それぞれ元のコードのまま表示します。失敗した図の件数は状態欄に一度だけ表示します。画像表示を利用できない場合もコードを表示します。
- PNGのキャッシュはtviの終了後も保持し、`mmdc` が見つからない場合も削除しません。次に文書を開いたとき、図のソースや変換設定が変わっていなければ再利用します。キャッシュ全体の上限はユーザーごとに128 MiBで、設定では変更できません。

画像にしたブロックのソースと、コードのまま表示したブロックの検索上の扱いは、[装飾・折り返しとの関係](search.md#装飾折り返しとの関係)を参照してください。

### 受け入れ条件

- 通常画像と、変換できる図・できない図が混在しても、各画像を正しい位置に表示し、失敗した図だけコードで読めます。元のファイルは変わりません。
- tviを再起動すると未変更の図を再利用し、図のソースを編集して開き直すとその図だけを再変換します。`PATH` から `mmdc` を外すとキャッシュがあってもコード表示になります。
