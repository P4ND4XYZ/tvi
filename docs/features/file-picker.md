# ファイルピッカー

[目次に戻る](../index.md)

表示中の文書が属するプロジェクトから、パスの一部を入力して別のMarkdown文書を開けます。本文検索、プレビュー、複数選択は行いません。

NORMALで `ff` を押すと、検索ルートからの相対パスが一覧に表示されます。検索ルートは文書のディレクトリから上に向かって探した、マーカーのファイルまたはディレクトリを含む最も近いディレクトリです。既定のマーカーは `.git` です。見つからなければ文書のディレクトリを使います。

| 入力 | 動作 |
|---|---|
| 文字入力 / Backspace | 相対パスを絞り込む。文字は入力順に一致すれば間が空いていてもよい。検索語が空ならパス順 |
| Ctrl-n / Ctrl-p | 次 / 前の候補を選ぶ。端では移動しない |
| Enter | 選択したファイルを同じ本文ビューで開く |
| Esc | ファイルを開かずに一覧を閉じる |
| Ctrl-o（一覧を閉じた後） | 開く前の文書と閲覧位置に戻る |

候補は `fd`（なければ `fdfind`）で列挙した `.md` ファイルです。`fd` の既定の隠しファイル・除外ルールが適用されます。列挙完了後に一覧を表示し、候補がなければ一覧は空のままです。列挙中のキャンセルはできません。両方のコマンドが見つからない場合は一覧を開かず、状態欄に `not found fd.` と表示します。起動や実行に失敗した場合は理由を表示します。

検索ルートのマーカーを変更するには、[init.lua](lua.md) で次のように指定します。

```lua
require("plugins.files").root_markers = { ".git", ".workspace" }
```
