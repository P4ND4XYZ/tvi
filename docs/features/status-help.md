# 状態表示とヘルプ

[目次に戻る](../index.md)

## 概要

閲覧中の状態と利用できる操作を確認するための機能です。

## 状態表示

画面下部に、次の情報を表示します。

- 現在のモード
- ファイル名
- 文書内の閲覧位置
- 検索状態。検索時の現在の一致番号と一致総数を含みます。

COMMANDまたはSEARCHモードでは、入力中のコマンドや検索語を入力欄に表示します。
操作に対する通知やエラーも状態欄に表示します。原因を詳しく調べるには、[診断ログ](diagnostic-log.md)を参照してください。

## ヘルプ

NORMALモードの`F1`、または`:help`でキー一覧を表示します。
キー一覧は本文に重ねて表示し、新しい動作モードは追加しません。
`Esc`で閉じると、元の文書表示へ戻ります。
キー一覧から、移動、モード切り替え、検索、[ファイルピッカー](file-picker.md)、終了の操作を確認できます。
